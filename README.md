# Student Performance Prediction (Machine Learning)

This project predicts whether a student will pass or fail based on study habits and lifestyle factors.

## Features
- Study hours
- Attendance percentage
- Sleep hours
- Phone usage

## Models Used
- Decision Tree Classifier
- Random Forest Classifier
- Logistic Regression

## Workflow
1. Data creation using pandas
2. Train-test split
3. Model training
4. Evaluation using accuracy score and confusion matrix

## Results
- Random Forest performed most consistently
- Logistic Regression showed more generalization
- Small dataset caused accuracy fluctuations

## Key Learnings
- Importance of training vs testing split
- Effect of dataset size on accuracy
- Differences between simple and complex models
- Overfitting in Decision Trees

## Tech Stack
- Python
- pandas
- scikit-learn
